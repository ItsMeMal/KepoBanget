# KepoBanget

Website kuis kepribadian ringan berbahasa Indonesia dengan desain mobile-first.

## Fitur
- 10 kuis interaktif dengan hasil berdasarkan jawaban.
- Tombol berbagi hasil menggunakan Web Share API atau salin teks.
- Layout responsif untuk desktop dan HP.
- Slot iklan yang disiapkan sebagai placeholder.

## Deploy ke Vercel
1. Import repository `ItsMeMal/KepoBanget` di https://vercel.com/new.
2. Framework Preset: **Other** (static HTML).
3. Root Directory: `./` (repository root).
4. Build Command: kosongkan.
5. Output Directory: kosongkan atau gunakan `.` jika dashboard mewajibkannya.
6. Klik **Deploy**.

## Memasang Adsterra
Ganti elemen bertuliskan `ADVERTISEMENT · SLOT IKLAN` dengan kode iklan resmi yang diberikan dari dashboard Adsterra. Jangan memasang kode Smartlink sebagai tombol palsu atau menutupi konten.

## Catatan
Hasil kuis hanya untuk hiburan, bukan penilaian psikologis atau diagnosis. Saat ini belum ada database atau login, karena kuis bisa dimainkan langsung di browser.
